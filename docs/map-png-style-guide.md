# 成长岛地图 PNG 美术规范

这份文档锁定地图资产的统一风格。`map-png-asset-inventory.md` 只回答“需要哪些图”，本文件回答“这些图要长什么样”。

## 核心方向

参考用户给出的动物森友会式 2.5D 家园图，但只取气质，不复制任何商业 IP 的角色、建筑、家具、构图或图标。

目标风格：

- 2.5D 等轴 / 俯视 3/4 角度。
- 马卡龙配色，低饱和、高明度、干净。
- 圆润厚地块，有玩具模型和纸雕场景的体积感。
- 建筑、栅栏、树、家具都有生活感，不是图标。
- 儿童友好，但不能像低价贴纸、PPT 插画或课堂剪贴画。
- 地图元素要能缩小后读得清楚，适合电子白板远距离观看。

## 统一镜头

所有地图 PNG 必须遵循同一透视：

- 视角：等轴或近似等轴，镜头从上方 35-45 度俯看。
- 地面：可见顶部面和前侧厚度。
- 门口方向：小屋门口统一朝画面下方或右下方。
- 光源：左上方柔光。
- 投影：统一向右下偏移，柔和、短，不要黑硬阴影。
- 轮廓：外轮廓清楚，边缘不要脏。

## 色彩

推荐主色：

- 海水：清亮青蓝、浅湖蓝。
- 草地：嫩绿、薄荷绿、黄绿色。
- 沙地：奶油黄、淡杏色。
- 木头：浅橡木、焦糖棕。
- 屋顶：珊瑚粉、奶油红、浅青绿、蓝灰、淡紫。
- 装饰：粉色栅栏、白色小花、浅黄灯光、暖白高光、贝壳粉、浅晶体点缀。

禁止：

- 大面积高饱和荧光色。
- 暗黑奇幻、灰脏战争风、写实泥土脏色。
- 所有区域使用同一套颜色，导致识别度不够。

## 资产类型规范

### 大底图层

适用于 `ocean-*`、`island-*`、`region-*`、`path-*`。

- 可以是完整画布层，尺寸按清单输出。
- `ocean-base` 可以不透明。
- 其他 overlay 建议透明 PNG。
- 同一类大图层要对齐同一世界坐标，不能每张构图漂移。
- 不要在图里写文字，不要放 UI。

### 地标建筑

适用于 `landmark-growth-tree`、`landmark-math-arena`、`landmark-old-street-gate` 等。

- 透明 PNG。
- 单个主体居中，底部留出 anchor 空间。
- 保留轻微自带接触阴影，但不要画大面积地面。
- 细节要足够丰富，能成为地图视觉焦点。
- 不要出现真实商业地标或商业游戏相似建筑。

### 小屋

适用于 `home-{type}-lv1/lv3/lv5/lv8`。

- 透明 PNG。
- 小屋必须有明显 homeType 差异，不能同一模型换色。
- 每种小屋四档升级要连续：更精致，但还是同一栋家。
- 门口必须清楚，方便精灵站在门前。
- 保留 12%-18% 安全边距，避免裁切屋顶、旗子、树叶。

小屋升级规则：

- Lv.1：基础小窝，结构简单。
- Lv.3：加门牌、窗、花草、小路。
- Lv.5：加围栏、灯、院子、个性装饰。
- Lv.8：守护者之家，装饰完整但仍然温柔可爱。

### 装饰物

适用于 `decor-*`。

- 透明 PNG。
- 单个物件或小组合，不要带复杂背景。
- 适合重复摆放，不要每个都太抢眼。
- 树、花、家具、栅栏要有统一比例。
- 栅栏、桥、石阶最好提供朝向一致的版本，后续再按需要扩展方向。

### 标签与提示

适用于 `label-*`。

- 优先做空白木牌、石碑、旗牌，不要把文字烘焙进图片。
- 文字由 React/Pixi 渲染，便于改名和多语言。
- 标签资产要像地图物件，不像网页按钮。

### 特效

适用于 `effect-*`。

- 透明 PNG。
- 柔和、克制、短时反馈。
- XP 光点、升级光环、选中提示都不要像战斗爆炸。
- 不要文字、数字、UI 边框、水印。

## 源图和手动抠图规则

现在不要求生图阶段自动出透明，也不要求 chroma-key。先直接生成源图，后续手动抠图。

源图建议：

1. 背景尽量简单、干净、无遮挡。
2. 主体边缘要清楚，方便手动抠图。
3. 不要生成棋盘格背景。
4. 原始源图先放在 `assets/generated/map-workbench/`。
5. 手动抠完后的最终 PNG 再放到 `public/assets/map/...`。
6. 最终透明 PNG 检查角落像素 alpha 是否为 0。

## 验收标准

每张图都要过这些检查：

- 风格像 2.5D 休闲养成游戏，不像后台系统素材。
- 没有文字、logo、水印、商业 IP 相似元素。
- 最终透明图必须是真 alpha，不是假透明。
- 缩小到 25%-35% 仍能看清轮廓。
- 透视、光源、投影方向和其他资产一致。
- 色彩温柔统一，但区域之间有差异。
- 放到地图上不会过度抢主体，也不会像临时占位图。
