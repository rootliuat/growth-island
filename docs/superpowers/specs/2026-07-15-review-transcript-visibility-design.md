# 老师复核卡识别内容可见性设计

## 目标

老师在点亮、修正、稍后、重说或跳过前，无需额外点击即可看到孩子刚才说了什么。展示层只消费现有 `transcript`，不改变识别、德育判断、复核或账本契约。

## 信息结构

复核卡按“状态 → 孩子与能量建议 → 孩子说 → 操作”排列。识别内容使用原生 `details`：折叠时显示“孩子说”标签、转写摘要与“全文”；展开时显示完整原文、置信度和“收起”。

摘要在桌面最多显示三行，移动端最多显示两行；短句不截断。异常长字符允许断行。空转写显示“未识别到文字，请孩子重说”。

## 视觉与触控

转写区沿用贝壳白、沙金细边框和深海文字，不增加独立卡片层级。展开/收起触控区至少 44px。展开长原文时由复核卡承担垂直滚动，地图不横向溢出，操作按钮保持现有两列布局与 52px 触控高度。

## 状态与兼容

摘要和全文来自同一个派生字符串，不新增 React 状态。`busy` 只锁定老师决策动作，不锁定记录展开。首页地图与孩子小屋继续复用同一复核卡；审批、修正、稍后、重说、跳过和 ledger 写入路径不变。

## 回归信号

- 待复核卡出现后，识别摘要默认可见且包含本轮 transcript。
- 长 transcript 折叠时受行数限制，展开后原文完整可读。
- 白板和移动端卡片均留在视口内，无横向溢出。
- 现有说成长安全 QA、构建和审批流程继续通过。

## 未采用方案

- 默认展开完整记录：长文本会把主要操作挤出首屏。
- 永久展示完整原文：无法稳定覆盖移动端和超长识别结果。
- 复制 transcript 到新状态：制造第二份真相，增加同步错误。
