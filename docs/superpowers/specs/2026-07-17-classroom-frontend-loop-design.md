# 课堂前端闭环设计

## 目标

保持地图清晰度、Provider、ledger 和导航契约不变，把“孩子说成长”收敛为可连续执行的单人闭环：识别过程可理解，失败动作与失败阶段一致，老师能原位接管，确认后明确显示账本收据，并能一键进入下一位。

## 方案选择

### 方案 A：继续修补地图浮卡

改动最小，但复核卡仍遮挡地图，移动端和超宽屏会继续累积绝对定位分支，不采用。

### 方案 B：复核任务轨道（采用）

地图仍是主舞台；桌面复核态把老师卡作为地图舞台的同级右轨，移动端变为底部 Sheet。现有状态与回调继续单向传递，不新建第二份会话状态。该方案能消除布局特殊情况，同时控制改动边界。

### 方案 C：重写首页 Shell 状态机

长期上限最高，但会同时改导航、Dock、地图和数据装配，超过本轮真实课堂闭环范围，不采用。

## 状态与错误动作

错误必须携带明确恢复动作，界面不得从错误文案猜测行为：

- 识别失败：重新识别或重说。
- 德育判断失败：重试判断或老师接管。
- 入账失败：重试点亮或放入待办，绝不回到录音。
- 麦克风或 Provider 不可用：老师接管或跳过这位。

老师接管留在当前孩子上下文，复用复核卡的能量调整能力。保存期间主按钮显示“点亮中…”，成功后显示孩子、能量增量和“已写入成长账本”。

## 复核证据与操作层级

复核区按“孩子与状态 → 识别原文 → 能量建议 → 主操作 → 次操作”排列。原文默认显示两至三行，可展开全文。`result.confidence` 改名为“成长判断把握”，不得冒充 ASR 置信度。

“修正”改名为“调能量”。本轮保留现有原始 transcript 数据契约；若加入文字修正，必须新增 `rawTranscript` 与 `correctedTranscript`，不得覆盖原始证据。本轮不为此扩张 server 持久化契约。

主操作只有“确认点亮”；“调能量、重说、放入待办”为次操作；“跳过这位”降级为低强调动作。中央儿童层不重复老师复核信息。

## 连续课堂

成功反馈目标时长为 0.8–1.2 秒，用户选择下一位时可立即中断。底部队列提供当前孩子之后的“下一位”快捷入口；选择后直接进入准备说状态。稍后处理的记录在首页老师入口显示待复核数量。

## 地图与超宽屏

不降低 Pixi renderer resolution，不使用 CSS scale 放大画布。修复活动气泡阈值高于相机最大缩放的不可达状态，阈值从相机配置派生。总览只突出当前孩子和必要标签。

超宽屏保留地图最大有效渲染宽度，额外空间承载稳定 HUD 轨道并延续海水背景；不把 Pixi 画布无限拉宽。移动端复核区统一为带安全区的底部 Sheet，主操作保持可见。

## 性能与可访问性

避免新增逐帧 React 状态和布局读取。图片补充尺寸与非关键懒加载；按钮保持至少 44px；异步状态使用现有 `aria-live`；所有新增动效服从 `prefers-reduced-motion`。

## 验证

- 单元测试覆盖错误阶段到恢复动作、入账失败重试和下一位选择。
- 浏览器 QA 覆盖白板/移动端原文可见、复核栏不遮主舞台、待办计数、成功收据和下一位。
- 构建预算、首页白板 QA、说成长流程 QA 与生产预览 smoke 全部通过。
- 2560px/3840px 不降低渲染比例，不出现灰色无功能空白。

## 范围边界

本轮不修改 Provider 协议、不降低地图分辨率、不重写 AppShell、不引入新的状态库，也不改变 ledger 幂等与课堂数据权威契约。
