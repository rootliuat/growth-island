# Map PNG Assets

Place generated map PNG files here. Vite serves this folder as `/assets/map/...`.

Required subfolders:

- `ocean`
- `island`
- `regions`
- `landmarks`
- `homes`
- `decorations`
- `paths`
- `labels`
- `effects`

Use `docs/map-png-asset-inventory.md` for asset IDs and sizes, `docs/map-png-style-guide.md` for art direction, and `docs/map-png-generation-guide.md` for WSL production steps.
