# Prompt Templates

Use one prompt per final image. Replace bracketed fields before generating.

## Spirit Egg

```text
Use case: stylized-concept
Asset type: chroma-key source sprite for a transparent RPG game sprite in Beihai Growth Island
Primary request: Create an original fantasy spirit egg for [spirit_name], state [state].
Subject: [state-specific description]. The egg should clearly preview [core motif] through shape, markings, glow, and tiny ornaments.
Style/medium: high-finish original fantasy RPG companion art, polished 2D anime fantasy illustration, elegant magical design, suitable for kindergarten children but not low-detail clip art.
Composition/framing: single centered full-body egg sprite, generous padding, perfectly flat solid [key_color] chroma-key background for background removal.
Lighting/mood: soft magical glow, gentle and hopeful.
Color palette: [palette], harmonious and refined.
Materials/textures: smooth shell, subtle magical markings, delicate ornament details.
Constraints: no text, no logo, no watermark, no UI, no background scene, no weapon, no scary expression, no checkerboard background, no cast shadow, no contact shadow, no floor plane. Do not use [key_color] anywhere in the subject.
Avoid: copying commercial IP characters, outfits, symbols, poses, or UI; avoid realistic 3D render, cheap sticker style, generic mascot look.
```

## Hatched Spirit Lv.2-Lv.8

```text
Use case: stylized-concept
Asset type: chroma-key source sprite for a transparent RPG game companion in Beihai Growth Island
Primary request: Create [spirit_name] [state], an original fantasy spirit companion.
Subject: [concept]. For this state, show [evolution requirement]. Keep it clearly the same spirit as earlier states.
Style/medium: premium original anime fantasy RPG companion, high-detail 2D illustration, refined magical creature or spirit design, beautiful but preschool-friendly.
Composition/framing: single centered full-body character, perfectly flat solid [key_color] chroma-key background for background removal, clean readable silhouette, generous padding.
Lighting/mood: luminous eyes, soft magical glow, gentle inviting expression.
Color palette: [palette], with tasteful accent colors; do not force every character into the same palette.
Materials/textures: delicate ornaments, soft fur/leaves/crystals/feathers/cloth-like magic details as appropriate.
Constraints: original character, no text, no logo, no watermark, no UI, no weapon, no scary monster, no realistic 3D render, no checkerboard background, no cast shadow, no contact shadow, no floor plane. Do not use [key_color] anywhere in the subject.
Avoid: copying Genshin Impact, Nahida, Pokemon, Digimon, Disney, Sanrio, or any commercial IP; do not reuse any existing character's hairstyle, outfit structure, accessories, pose, symbols, or color layout.
```

## Main Map

```text
Use case: illustration-story
Asset type: 16:9 game map background
Primary request: Create the Beihai Growth Island main map for a kindergarten fantasy growth game.
Scene/backdrop: a warm hand-painted island world with Silver Beach, mangrove forest, old street, pearl bay, small dock, growth tree, math magic arena, leaderboard stage, and 40 pet home slots.
Style/medium: hand-painted fantasy storybook RPG map, warm watercolor and gouache texture, paper-diorama depth, premium game background.
Composition/framing: wide 1920x1080 map, readable zones, clear empty slots for pets, no tiny unreadable labels.
Lighting/mood: bright, magical, adventurous, preschool-friendly.
Constraints: no commercial IP, no dark medieval castle, no dragon, no horror, no text-heavy UI.
```
